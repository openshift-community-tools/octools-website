What’s New

Recent additions and major updates across OCT extensions

Day-2 nested storage and virtualization; Windows 11 pre-flight Update

Shift-on-Shift Virt 0.7 can add nested storage or OpenShift Virtualization to a cluster that is already running, restarting its nodes one at a time (community contribution). Windows Builder 1.1 checks the storage OpenShift Virtualization uses for VM state and explains how to fix it when Windows 11 VMs would never start, including on clusters with only block storage.

Per-node static IPv4 for bonds and bridges Update

Network Bond 0.3 and Network Bridge 1.2 can target single nodes and give each node its own static IPv4 address. Addresses already in use are refused, and per-node policies roll out one node at a time. Community contribution. Storefront 1.6.1 also shows your own rating on each tile and counts each cluster once in the download numbers.

Security framework New

Storefront 1.6 shows what a tool will be allowed to do before it is installed: permissions with reasons, privileged access, Routes and images, and on Update what changed. Cluster admins can set an optional policy (warn or enforce, allowed registries, telemetry and more) and apply an admission policy pack. Backends now check each request against the signed-in user's own permissions. Community contribution, with Shift-on-Shift Virt 0.6, Bare Metal 0.2 and DHCP 1.1.

Must-Gather New

Run oc adm must-gather from the console: full, networking, storage, virtualization and more, with optional audit logs and obfuscation, then download the archive ready for a support case. It runs with your own credentials and needs no extra permissions in the cluster. Community contribution, in the storefront from 1.5.27.

A home of its own Update

OpenShift Community Tools now lives in project-owned accounts: github.com/openshift-community-tools and quay.io/openshift-community-tools, with several maintainers. Old links redirect and existing installs keep working.

Shift-on-Shift Express New

Shift-on-Shift Virt 0.5 can clone a nested cluster from a master instead of installing it: console up in about 8 minutes and oc login in about 15, versus about an hour for an install. Each clone gets its own name, addresses, host routes and credentials, and can add nested storage and OpenShift Virtualization. 0.5.1 also publishes nested applications under the hosting cluster's *.apps with its trusted certificate, no DNS needed.

Shift-on-Shift Virt 0.4 Update

OpenShift 5.0 support, and every install now gets the newest release of the chosen version. Nested OpenShift Virtualization runs VMs, and masters spread across hosts (community contributions). Host routes: open a nested cluster’s console and log in with oc through the hosting cluster’s routes, with no DNS records. Choose OVN-Kubernetes, Calico or Cilium for nested 4.22 clusters, with every CNI image pinned by digest (community contributions).

Shift-on-Shift Virt Update

The bastion VM is now the load balancer, so new nested clusters are reachable from routed networks on Linux bridge and OVN localnet VLANs. IP pools offer free external addresses, and the wizard refuses network settings that cannot work.

Network Bond Update

Community contributions: balance-xor transmit hash policies (including vlan+srcmac) and real OVS balance-slb bonds with a dynamic rebalancing interval. Bond changes now roll out one node at a time.

Network Bridge & Network VLAN Update

MTU setting with jumbo-frame detection: 9000 is suggested when the uplink supports it on every node, and values above the uplink MTU are blocked.

Network Bridge Update

Protects NICs shared with ODF, br-ex or macvlan networks: bridges go on a VLAN interface by default, whole-NIC changes need confirmation, and affected pods can be restarted one at a time.

Windows Builder Update

Installs Windows updates before sysprep, shows live build progress, and running builds can be cancelled.

ODF Macvlans New

Move ODF onto dedicated macvlan public and cluster networks, with the Rook Multus validation test before anything changes.

Quick Start

Three steps to community tools in your OpenShift Console

Install the Storefront

Apply the install manifest to deploy the OCT storefront plugin into your cluster.

oc apply -f https://raw.githubusercontent.com/openshift-community-tools/oct-storefront/main/deploy/install.yaml

Browse the Catalog

Open the OpenShift Console. Navigate to Community Tools in the sidebar. Browse extensions by category: Compute, Storage, Network, Management.

Add Extensions

Click Add on any tile. The storefront creates the namespace, deploys the plugin, and enables it in your console.

Uninstall

To remove all OCT extensions from your cluster, run the uninstall script:

bash <(curl -s https://raw.githubusercontent.com/openshift-community-tools/oct-storefront/main/deploy/uninstall.sh)

Removes all oct-* namespaces, ConsolePlugins, and RBAC. System plugins are not affected. Learn more →
